# FADIDE---Frontend
FADIDE - Sistema web para la gestión de contratos y supervisión de obras

## Tecnologías
Angular 22 · Angular Material · Signals · JWT (backend Spring Boot en `http://localhost:8080`)

## Ejecutar
1. Levantar el backend (FADIDE---Backend) con PostgreSQL `sisco_db`.
2. `npm install`
3. `ng serve` y abrir http://localhost:4200
